UC Teste de Sistemas · Aula 14 — Prática Guiada Testando POST, listagem e erro 404

Prática guiada — completando o TarefaControllerTest

Siga os passos abaixo para testar criação, listagem e o cenário de erro 404.

1
Configurar a classe de teste
▶

Configure @WebMvcTest, MockMvc, ObjectMapper e o @MockBean do TarefaService.

@WebMvcTest(TarefaController.class)
class TarefaControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @MockBean
    private TarefaService tarefaService;
}
ObjectMapper é a classe do Jackson que converte objetos Java em JSON (e vice-versa) — o Spring Boot já a disponibiliza automaticamente para injeção.
2
Testar o POST de criação
▶

Simule uma requisição POST enviando um JSON no corpo da requisição.

@Test
void criarTarefaDeveRetornarTarefaCriada() throws Exception {
    Tarefa nova = new Tarefa("Estudar Spring");
    when(tarefaService.criar(any())).thenReturn(nova);

    mockMvc.perform(post("/tarefas")
            .contentType(MediaType.APPLICATION_JSON)
            .content(objectMapper.writeValueAsString(nova)))
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.titulo").value("Estudar Spring"));
}
"objectMapper.writeValueAsString(nova)" transforma o objeto Java em uma String JSON, exatamente como um cliente HTTP real enviaria.
3
Testar a listagem completa
▶

Simule o retorno de duas tarefas e confirme o tamanho da lista no JSON.

@Test
void listarTodasDeveRetornarListaCompleta() throws Exception {
    when(tarefaService.listarTodas())
        .thenReturn(List.of(new Tarefa("T1"), new Tarefa("T2")));

    mockMvc.perform(get("/tarefas"))
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.length()").value(2));
}
"$.length()" no jsonPath verifica o tamanho de um array JSON — útil para confirmar quantos itens vieram na resposta.
4
Testar o cenário de erro 404
▶

Simule o Service lançando a exceção de "não encontrado" e confirme o status 404.

@Test
void buscarPorIdInexistenteDeveRetornar404() throws Exception {
    when(tarefaService.buscarPorId(99L))
        .thenThrow(new TarefaNaoEncontradaException());

    mockMvc.perform(get("/tarefas/99"))
        .andExpect(status().isNotFound());
}
Para o status 404 funcionar de verdade, é preciso um @ExceptionHandler mapeando TarefaNaoEncontradaException — vamos revisar isso na Aula 15.
5
Executar toda a suíte do Controller
▶

Rode a classe TarefaControllerTest inteira e confirme que todos os cenários HTTP passam.

Tests passed: 4 of 4 test — 180ms
Note como cada camada (Controller, Service, Repository) tem sua própria suíte de testes, testada de forma independente e focada.
