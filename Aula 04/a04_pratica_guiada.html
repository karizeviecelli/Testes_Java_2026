UC Teste de Sistemas · Aula 04 — Prática Guiada Aplicando AAA e assertAll

Prática guiada — testando a classe Triangulo

Siga os passos abaixo para praticar o padrão AAA e as principais asserções em uma entidade nova.

1
Criar a entidade Triangulo
▶

Crie a classe Triangulo com três lados (double), validando no construtor que nenhum lado é ≤ 0.

public class Triangulo {
    private double ladoA, ladoB, ladoC;

    public Triangulo(double a, double b, double c) {
        if (a <= 0 || b <= 0 || c <= 0)
            throw new IllegalArgumentException("Lados devem ser positivos.");
        this.ladoA = a; this.ladoB = b; this.ladoC = c;
    }

    public double calcularPerimetro() { return ladoA + ladoB + ladoC; }
}
Podemos declarar vários atributos do mesmo tipo em uma linha só, separados por vírgula: "double ladoA, ladoB, ladoC;"
2
Escrever um teste com Arrange-Act-Assert
▶

Escreva um teste para calcularPerimetro(), deixando visíveis os comentários AAA.

@Test
void calcularPerimetroDeveSomarOsTresLados() {
    // Arrange
    Triangulo triangulo = new Triangulo(3, 4, 5);
    // Act
    double perimetro = triangulo.calcularPerimetro();
    // Assert
    assertEquals(12.0, perimetro);
}
Manter os comentários // Arrange, // Act, // Assert ajuda muito a treinar o hábito — depois de um tempo, você faz isso automaticamente, sem precisar comentar.
3
Testar a exceção com assertThrows
▶

Confirme que criar um Triangulo com lado negativo lança IllegalArgumentException.

@Test
void ladoNegativoDeveLancarExcecao() {
    assertThrows(
        IllegalArgumentException.class,
        () -> new Triangulo(-1, 4, 5)
    );
}
Repare que aqui o Arrange e o Act "se fundem" dentro da lambda — isso é comum em testes de exceção.
4
Agrupar verificações com assertAll
▶

Escreva um teste que confirme os três lados de uma vez, usando assertAll.

@Test
void triangulo3_4_5DeveTerLadosCorretos() {
    Triangulo t = new Triangulo(3, 4, 5);
    assertAll(
        () -> assertEquals(3.0, t.getLadoA()),
        () -> assertEquals(4.0, t.getLadoB()),
        () -> assertEquals(5.0, t.getLadoC())
    );
}
Lembre-se de criar os getters getLadoA(), getLadoB() e getLadoC() na classe Triangulo.
5
Revisar nomes de teste e executar
▶

Releia os nomes dos seus métodos de teste: eles contam a história (o quê + condição + resultado esperado)? Depois, rode a classe inteira.
