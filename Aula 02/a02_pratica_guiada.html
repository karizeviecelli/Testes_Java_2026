Prática guiada — projeto Maven + pom.xml

Siga os passos abaixo, na ordem, para configurar corretamente o ambiente que usaremos no restante da UC.

1
Criar o projeto Maven no IntelliJ
▶

No IntelliJ: File → New → Project → selecione Maven, escolha o JDK 17 (ou disponível) e defina um nome de projeto.

Se o IntelliJ perguntar sobre "Archetype", pode deixar em branco/None — vamos configurar o pom.xml manualmente.
2
Definir as coordenadas GAV e properties
▶

No pom.xml, ajuste o groupId/artifactId/version e defina as properties de Java 17 e encoding UTF-8.

<groupId>br.edu.testesistemas</groupId>
<artifactId>teste-sistemas-turma</artifactId>
<version>1.0-SNAPSHOT</version>

<properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>
O encoding UTF-8 evita problemas com acentuação em comentários e strings do seu código — sempre configure isso desde o início.
3
Adicionar a dependência do JUnit 5
▶

Insira o bloco <dependencies> com o junit-jupiter em scope test.

<dependencies>
    <dependency>
        <groupId>org.junit.jupiter</groupId>
        <artifactId>junit-jupiter</artifactId>
        <version>5.10.2</version>
        <scope>test</scope>
    </dependency>
</dependencies>
Depois de salvar o pom.xml, o IntelliJ costuma mostrar um ícone de "reload" do Maven no canto — clique nele para baixar a dependência.
4
Adicionar o maven-surefire-plugin
▶

Insira o bloco <build> com o plugin responsável por executar os testes.

<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-surefire-plugin</artifactId>
            <version>3.2.5</version>
        </plugin>
    </plugins>
</build>
Sem esse plugin, o "mvn test" pode não executar corretamente os testes escritos com JUnit 5.
5
Migrar as entidades e compilar
▶

Mova Produto e ContaBancaria (Aula 01) para src/main/java/br/edu/testesistemas/entidades e rode mvn compile.

$ mvn compile ... [INFO] BUILD SUCCESS
Se aparecer erro de pacote (package), confirme se a declaração "package br.edu.testesistemas.entidades;" está no topo de cada classe.
