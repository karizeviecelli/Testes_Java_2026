UC Teste de Sistemas · Aula 09 — Prática Guiada Testando retentativa com thenReturn encadeado

Prática guiada — ServicoConsulta com retentativa

Siga os passos abaixo para praticar @InjectMocks e retornos consecutivos diferentes.

1
Criar a interface ServicoBancoExterno
▶

Crie a interface com o método double consultarSaldo().

public interface ServicoBancoExterno {
    double consultarSaldo();
}
Essa interface representa um sistema bancário externo — algo que pode falhar temporariamente, por isso o cenário de retentativa faz sentido aqui.
2
Criar ServicoConsulta com lógica de retentativa
▶

Implemente o método que tenta consultar, e se falhar, tenta mais uma vez.

public class ServicoConsulta {
    private ServicoBancoExterno bancoExterno;

    public ServicoConsulta(ServicoBancoExterno bancoExterno) {
        this.bancoExterno = bancoExterno;
    }

    public double consultarSaldoComRetentativa() {
        try {
            return bancoExterno.consultarSaldo();
        } catch (RuntimeException e) {
            return bancoExterno.consultarSaldo();
        }
    }
}
Esse padrão de "tentar de novo uma vez em caso de falha" é comum em sistemas reais que dependem de serviços externos instáveis.
3
Configurar a classe de teste com @InjectMocks
▶

Declare o mock e a classe testada, deixando o Mockito conectar os dois.

@ExtendWith(MockitoExtension.class)
class ServicoConsultaTest {

    @Mock
    private ServicoBancoExterno bancoExternoMock;

    @InjectMocks
    private ServicoConsulta servicoConsulta;
}
O @InjectMocks só funciona bem quando há um único construtor "óbvio" para o Mockito usar — tenha isso em mente ao projetar suas classes.
4
Programar a falha seguida de sucesso
▶

Use thenThrow seguido de thenReturn para simular a retentativa.

@Test
void consultarSaldoDeveTentarNovamenteAposFalha() {
    when(bancoExternoMock.consultarSaldo())
        .thenThrow(new RuntimeException("indisponível"))
        .thenReturn(1500.0);

    double resultado = servicoConsulta.consultarSaldoComRetentativa();

    assertEquals(1500.0, resultado);
}
A ORDEM importa: a primeira chamada usa o primeiro "thenX", a segunda chamada usa o segundo, e assim por diante.
5
Executar e confirmar o número de chamadas
▶

Adicione um verify confirmando que consultarSaldo() foi chamado exatamente 2 vezes.

    verify(bancoExternoMock, times(2)).consultarSaldo();
Esse verify prova que a lógica de retentativa realmente tentou duas vezes — não é só "sorte" o teste ter passado.
