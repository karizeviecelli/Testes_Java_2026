Prática guiada — testando com um Fake de repositório

Siga os passos abaixo para criar um Fake funcional e usá-lo para testar uma classe de serviço isoladamente.

1
Definir a interface RepositorioUsuario
▶

Crie a interface com os métodos salvar(Usuario) e buscarPorEmail(String).

public interface RepositorioUsuario {
    void salvar(Usuario usuario);
    Usuario buscarPorEmail(String email);
}
Interfaces definem "o que" uma classe deve fazer, sem dizer "como" — por isso são ideais para trocar a implementação real por um dublê.
2
Criar o Fake em memória
▶

Implemente RepositorioUsuarioFake, guardando os usuários em uma lista.

public class RepositorioUsuarioFake implements RepositorioUsuario {
    private List<Usuario> usuarios = new ArrayList<>();

    @Override
    public void salvar(Usuario usuario) { usuarios.add(usuario); }

    @Override
    public Usuario buscarPorEmail(String email) {
        return usuarios.stream()
            .filter(u -> u.getEmail().equals(email))
            .findFirst().orElse(null);
    }
}
Esse Fake é uma implementação real e funcional — só que "persiste" em uma lista da memória, não em um banco de dados de verdade.
3
Criar o serviço CadastroUsuario
▶

Crie a classe que depende de RepositorioUsuario (via construtor) e tem o método cadastrar().

public class CadastroUsuario {
    private RepositorioUsuario repositorio;

    public CadastroUsuario(RepositorioUsuario repositorio) {
        this.repositorio = repositorio;
    }

    public void cadastrar(Usuario usuario) {
        if (repositorio.buscarPorEmail(usuario.getEmail()) != null)
            throw new IllegalStateException("E-mail já cadastrado.");
        repositorio.salvar(usuario);
    }
}
Repare que CadastroUsuario depende só da INTERFACE — não sabe (e não precisa saber) se está usando o Fake ou uma implementação real de banco.
4
Testar o cadastro com sucesso
▶

Usando o Fake, teste que cadastrar um novo usuário funciona e ele passa a ser encontrado.

@Test
void cadastrarNovoUsuarioDeveSalvarNoRepositorio() {
    RepositorioUsuarioFake fake = new RepositorioUsuarioFake();
    CadastroUsuario cadastro = new CadastroUsuario(fake);

    cadastro.cadastrar(new Usuario("Ana", "ana@email.com"));

    assertNotNull(fake.buscarPorEmail("ana@email.com"));
}
Aqui usamos o Fake tanto para "preparar" o cenário quanto para "verificar" o resultado — bem prático!
5
Testar o cadastro duplicado
▶

Teste que cadastrar um e-mail já existente lança IllegalStateException.

@Test
void cadastrarEmailDuplicadoDeveLancarExcecao() {
    RepositorioUsuarioFake fake = new RepositorioUsuarioFake();
    CadastroUsuario cadastro = new CadastroUsuario(fake);
    cadastro.cadastrar(new Usuario("Ana", "ana@email.com"));

    assertThrows(IllegalStateException.class, () ->
        cadastro.cadastrar(new Usuario("Outra Ana", "ana@email.com"))
    );
}
Nenhum banco de dados real foi usado em nenhum dos dois testes — e ainda assim testamos a regra de negócio com confiança total.
