Prática guiada — pedido integrado

Construa as unidades, integre-as gradualmente e use as evidências dos testes para diagnosticar uma falha.

1Criar Produto com validação▶

Implemente nome, preço, construtor e getters. Rejeite preço menor ou igual a zero.

public class Produto {
    private String nome;
    private double preco;

    public Produto(String nome, double preco) {
        if (preco <= 0) {
            throw new IllegalArgumentException("Preço deve ser maior que zero");
        }
        this.nome = nome;
        this.preco = preco;
    }
    public double getPreco() { return preco; }
}
Crie também um teste com assertThrows para preço zero.
2Criar Pedido▶

Use uma lista de produtos e implemente adicionarProduto e calcularTotal.

private List<Produto> produtos = new ArrayList<>();

public void adicionarProduto(Produto produto) {
    produtos.add(produto);
}

public double calcularTotal() {
    double total = 0;
    for (Produto produto : produtos) {
        total += produto.getPreco();
    }
    return total;
}
Importe java.util.ArrayList e java.util.List.
3Testar um produto no Pedido▶

Crie a primeira evidência de colaboração.

@Test
void pedidoComUmProdutoDeveRetornarSeuPreco() {
    Produto mouse = new Produto("Mouse", 100);
    Pedido pedido = new Pedido();

    pedido.adicionarProduto(mouse);

    assertEquals(100, pedido.calcularTotal(), 0.001);
}
Pergunte: este cenário depende de quantas classes reais?
4Testar vários produtos▶

Adicione três produtos e calcule manualmente o esperado antes do assert.

Produto p1 = new Produto("Mouse", 100);
Produto p2 = new Produto("Teclado", 200);
Produto p3 = new Produto("Webcam", 150);

// Total esperado: 450
Não escreva 450 por tentativa: some os valores antes.
5Criar e testar CalculadoraDesconto▶

Teste primeiro a nova regra isoladamente.

@Test
void deveAplicarDezPorCento() {
    CalculadoraDesconto calc = new CalculadoraDesconto();

    assertEquals(90, calc.aplicar(100, 10), 0.001);
}
Uma integração fica mais fácil de diagnosticar quando suas peças também têm testes menores.
6Integrar desconto ao Pedido▶

Faça Pedido usar o total calculado como entrada da calculadora.

public double calcularTotalComDesconto(double percentual) {
    double total = calcularTotal();
    CalculadoraDesconto calculadora = new CalculadoraDesconto();
    return calculadora.aplicar(total, percentual);
}
Teste R$ 300 com 10%. O resultado esperado é R$ 270.
7Provocar e investigar uma falha▶

Troque += por -= em calcularTotal, execute tudo e registre a evidência.

// defeito temporário
total -= produto.getPreco();

// Registre:
// 1. teste que falhou;
// 2. esperado;
// 3. obtido;
// 4. teste menor que ajudou no diagnóstico.
Depois da investigação, restaure += e deixe toda a suíte verde.
