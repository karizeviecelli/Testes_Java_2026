UC Teste de Sistemas · Aula 10 — Prática Guiada Configurando JaCoCo e cobrindo branches

Prática guiada — cobertura completa de FaixaDeFrete

Siga os passos abaixo para configurar o JaCoCo e alcançar 100% de cobertura de linha e branch.

1
Adicionar o plugin do JaCoCo
▶

No pom.xml, adicione o jacoco-maven-plugin dentro do bloco build/plugins.

<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>0.8.12</version>
    <executions>
        <execution>
            <goals><goal>prepare-agent</goal></goals>
        </execution>
        <execution>
            <id>report</id>
            <phase>test</phase>
            <goals><goal>report</goal></goals>
        </execution>
    </executions>
</plugin>
"prepare-agent" instrumenta o código ANTES dos testes rodarem; "report" gera o HTML DEPOIS que os testes terminam.
2
Criar a classe FaixaDeFrete
▶

Crie uma classe com múltiplos caminhos de decisão, calculando o frete por faixa de peso.

public class FaixaDeFrete {
    public double calcular(double pesoKg) {
        if (pesoKg <= 1) {
            return 10.0;
        } else if (pesoKg <= 5) {
            return 25.0;
        } else {
            return 50.0;
        }
    }
}
Essa classe tem TRÊS branches — vai precisar de pelo menos 3 testes diferentes para cobri-los todos.
3
Escrever apenas um teste (propositalmente incompleto)
▶

Escreva só o teste do primeiro caminho e rode o JaCoCo para ver a cobertura parcial.

@Test
void pesoAte1kgDeveCustar10() {
    assertEquals(10.0, faixaDeFrete.calcular(0.5));
}
Rode "mvn test" e abra target/site/jacoco/index.html — você vai ver os outros dois caminhos em vermelho ou amarelo.
4
Completar a cobertura dos branches restantes
▶

Adicione os dois testes que faltam, cobrindo os outros caminhos de decisão.

@Test
void pesoEntre1e5kgDeveCustar25() {
    assertEquals(25.0, faixaDeFrete.calcular(3.0));
}

@Test
void pesoAcimaDe5kgDeveCustar50() {
    assertEquals(50.0, faixaDeFrete.calcular(8.0));
}
Repare que testamos um valor "confortável" dentro de cada faixa — na próxima aula vamos discutir também os valores de FRONTEIRA (1.0 e 5.0 exatos).
5
Rodar novamente e confirmar 100%
▶

Rode "mvn test" de novo e confirme que Instructions e Branches estão ambos em 100% no relatório do JaCoCo.

FaixaDeFrete.calcular()
  Instructions: 100%   Branches: 100%
Mesmo com 100%, pergunte-se: testei valores exatamente NO limite (1.0kg e 5.0kg)? Cobertura de branch não substitui um bom raciocínio de casos de teste.
