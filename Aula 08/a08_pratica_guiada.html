UC Teste de Sistemas · Aula 08 — Prática Guiada Mockando um serviço de e-mail

Prática guiada — mockando o NotificadorPedido

Siga os passos abaixo para usar @Mock, when/thenReturn e verify em um cenário de notificação por e-mail.

1
Adicionar as dependências do Mockito
▶

No pom.xml, adicione mockito-core e mockito-junit-jupiter, ambos com scope test.

<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-junit-jupiter</artifactId>
    <version>5.11.0</version>
    <scope>test</scope>
</dependency>
O mockito-junit-jupiter já traz o mockito-core como dependência transitiva, mas é comum declarar os dois explicitamente por clareza.
2
Anotar a classe de teste e declarar o mock
▶

Use @ExtendWith(MockitoExtension.class) na classe e @Mock no atributo ServicoEmail.

@ExtendWith(MockitoExtension.class)
class NotificadorPedidoTest {

    @Mock
    private ServicoEmail servicoEmailMock;
}
Sem o @ExtendWith(MockitoExtension.class), o Mockito não processa as anotações @Mock automaticamente.
3
Programar o mock com when/thenReturn
▶

Simule que o envio de e-mail sempre é bem-sucedido.

@Test
void notificarDeveEnviarEmailComSucesso() {
    when(servicoEmailMock.enviar(anyString(), anyString()))
        .thenReturn(true);
}
anyString() é um matcher que aceita qualquer String como argumento — útil quando o valor exato não importa para o teste.
4
Executar a ação e verificar a chamada
▶

Chame notificar() e confirme, com verify, que enviar() foi chamado exatamente uma vez.

    NotificadorPedido notificador = new NotificadorPedido(servicoEmailMock);
    Pedido pedido = new Pedido("cliente@email.com");

    notificador.notificar(pedido);

    verify(servicoEmailMock, times(1))
        .enviar("cliente@email.com", anyString());
}
Repare que passamos o e-mail exato ("cliente@email.com") no verify, mas usamos anyString() para a mensagem — podemos misturar valores exatos e matchers.
5
Executar e revisar
▶

Rode o teste e reflita: nenhum e-mail real foi enviado, mas temos certeza de que o método CERTO foi chamado, com os argumentos CERTOS.

Tests passed: 1 of 1 test — 4ms
Essa é a força do Mockito: garantimos comportamento E interação, sem tocar em nenhum sistema externo real.
