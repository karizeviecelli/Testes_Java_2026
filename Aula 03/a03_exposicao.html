A primeira audiência

Convocando a primeira testemunha

Com o cartório pronto, hoje abrimos a primeira audiência de verdade. Cada @Test é uma audiência independente: o JUnit convoca o "réu" (nosso código), ouve o caso e anuncia o veredito — verde (passou) ou vermelho (falhou).

Convenção

Onde os testes moram

Toda classe de teste vive em src/test/java, espelhando o pacote da classe testada.

Livro.java
src/test/java/br/edu/testesistemas/entidades/LivroTest.java  ← mesmo pacote

Exemplo

A entidade Livro

public class Livro {

```
private String titulo;
private String autor;
private boolean emprestado;


// Construtor
public Livro(String titulo, String autor) {
    this.titulo = titulo;
    this.autor = autor;
    this.emprestado = false;
}


// Realiza o empréstimo do livro
public void emprestar() {

    if (emprestado) {
        throw new IllegalStateException(
            "O livro já está emprestado."
        );
    }

    emprestado = true;
}


// Informa se o livro está emprestado
public boolean isEmprestado() {
    return emprestado;
}
```

}
Exemplo

LivroTest: primeira classe de teste

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertFalse;

public class LivroTest {

```
private Livro livro;


@BeforeEach
void configurarCadaTeste() {

    livro = new Livro(
        "Clean Code",
        "R. Martin"
    );
}


@Test
void livroDeveEstarDisponivel() {

    // Verifica se um livro novo não está emprestado
    assertFalse(livro.isEmprestado());
}
```

}

O @BeforeEach cria um novo objeto Livro antes de cada teste, garantindo que um teste não interfira no resultado do outro.

Boas práticas

@BeforeEach vs. compartilhar um único objeto

✗ UM ÚNICO OBJETO PARA TODOS OS TESTES

  • Um teste pode alterar o estado que outro depende
  • Ordem de execução passa a importar (perigoso!)
  • Bugs difíceis de reproduzir

✓ @BeforeEach cria um objeto novo

  • Cada teste começa do zero, isolado
  • Testes podem rodar em qualquer ordem
  • Falhas são previsíveis e fáceis de depurar
