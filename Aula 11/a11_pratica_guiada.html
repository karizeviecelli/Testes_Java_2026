UC Teste de Sistemas · Aula 11 — Prática Guiada TDD para uma fila de atendimento

Prática guiada — TDD para uma FilaAtendimento

Siga rigorosamente o ciclo Red-Green-Refactor para construir uma fila simples, do zero.

1
RED — Escrever o teste de "entrar na fila"
▶

Antes de criar a classe FilaAtendimento, escreva o teste que descreve o comportamento esperado.

@Test
void entrarNaFilaDeveAumentarTamanho() {
    FilaAtendimento fila = new FilaAtendimento();
    fila.entrar("Ana");
    assertEquals(1, fila.tamanho());
}
Nesse momento o código nem compila — isso é esperado! É o "Red" do ciclo.
2
GREEN — Implementação mínima
▶

Crie a classe com o mínimo necessário para o teste passar.

public class FilaAtendimento {
    private List<String> pessoas = new ArrayList<>();

    public void entrar(String nome) {
        pessoas.add(nome);
    }

    public int tamanho() {
        return pessoas.size();
    }
}
Rode o teste agora — ele deve passar (Green). Resista à tentação de já implementar "atender()" — um passo de cada vez!
3
RED — Escrever o teste de "atender"
▶

Escreva o teste para o próximo comportamento: atender deve retornar e remover o primeiro da fila.

@Test
void atenderDeveRetornarPrimeiroEDiminuirTamanho() {
    FilaAtendimento fila = new FilaAtendimento();
    fila.entrar("Ana");
    fila.entrar("Bruno");

    String atendido = fila.atender();

    assertEquals("Ana", atendido);
    assertEquals(1, fila.tamanho());
}
Esse teste vai falhar de cara — o método atender() ainda não existe. Isso é o Red do segundo ciclo.
4
GREEN — Implementar atender()
▶

Adicione o método, respeitando a ordem de chegada (fila = FIFO).

public String atender() {
    return pessoas.remove(0);
}
"pessoas.remove(0)" já retorna o elemento removido — perfeito para esse caso.
5
RED-GREEN — Tratar fila vazia + REFACTOR final
▶

Escreva um teste para atender() em fila vazia (deve lançar exceção), implemente, e revise o código final.

@Test
void atenderFilaVaziaDeveLancarExcecao() {
    FilaAtendimento fila = new FilaAtendimento();
    assertThrows(IllegalStateException.class, fila::atender);
}

// GREEN:
public String atender() {
    if (pessoas.isEmpty())
        throw new IllegalStateException("Fila vazia.");
    return pessoas.remove(0);
}
"fila::atender" é uma referência de método — equivalente a "() -> fila.atender()", mais curto para passar ao assertThrows.
