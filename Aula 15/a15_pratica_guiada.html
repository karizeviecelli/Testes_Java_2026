Prática guiada — funcionalidade completa "concluir tarefa"

Siga os passos abaixo para implementar e testar uma funcionalidade nova, de ponta a ponta, pelas três camadas.

1
Adicionar o método concluir() ao Service
▶

Reaproveite buscarPorId() e adicione a lógica de marcar como concluída.

public Tarefa concluir(Long id) {
    Tarefa tarefa = buscarPorId(id);
    tarefa.setConcluida(true);
    return tarefaRepository.save(tarefa);
}
Reaproveitar buscarPorId() evita duplicar a lógica de "não encontrado" — um bom exemplo de reuso dentro do próprio Service.
2
Testar o Service isoladamente
▶

Use Mockito puro, mockando o Repository.

@Test
void concluirDeveMarcarTarefaComoConcluida() {
    Tarefa tarefa = new Tarefa("Estudar Spring");
    when(tarefaRepository.findById(1L)).thenReturn(Optional.of(tarefa));
    when(tarefaRepository.save(any())).thenReturn(tarefa);

    Tarefa resultado = tarefaService.concluir(1L);

    assertTrue(resultado.isConcluida());
}
Repare: testamos o Service SEM subir o Spring e SEM tocar no banco — exatamente a estratégia da Aula 12.
3
Adicionar o endpoint no Controller
▶

Crie o endpoint PUT que delega ao Service.

@PutMapping("/{id}/concluir")
public Tarefa concluir(@PathVariable Long id) {
    return tarefaService.concluir(id);
}
PUT é o verbo HTTP semanticamente mais apropriado para uma atualização de estado como essa.
4
Testar o Controller com MockMvc
▶

Simule a requisição PUT e verifique o corpo da resposta.

@Test
void concluirDeveRetornar200ComTarefaAtualizada() throws Exception {
    Tarefa concluida = new Tarefa("Estudar Spring");
    concluida.setConcluida(true);
    when(tarefaService.concluir(1L)).thenReturn(concluida);

    mockMvc.perform(put("/tarefas/1/concluir"))
        .andExpect(status().isOk())
        .andExpect(jsonPath("$.concluida").value(true));
}
Não esqueça de importar "put" estaticamente de MockMvcRequestBuilders, junto com get e post.
