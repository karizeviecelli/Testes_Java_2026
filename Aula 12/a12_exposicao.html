A boa notícia

Testar um @Service é o que já sabemos!

@ExtendWith(MockitoExtension.class) // NÃO @SpringBootTest!
class CheckoutServiceTest {

    @Mock
    private ServicoPagamento servicoPagamentoMock;

    @InjectMocks
    private CheckoutService checkoutService;
}
Escolha certa

Mockito puro vs. @SpringBootTest

✓ MOCKITO PURO (preferir sempre que possível)

  • Não sobe o contexto do Spring
  • Testes rápidos, ideais para a camada de Service

@SpringBootTest

  • Sobe o contexto COMPLETO da aplicação
  • Mais lento — reservar para testes de integração genuínos
