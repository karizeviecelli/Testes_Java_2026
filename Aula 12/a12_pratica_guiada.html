Prática guiada — testando ClienteService

Siga os passos abaixo para criar e testar um @Service Spring, sem subir o contexto da aplicação.

1
Criar a interface RepositorioCliente
▶

Crie a interface com o método buscarPorId.

public interface RepositorioCliente {
    Cliente buscarPorId(Long id);
}
Em uma aplicação Spring real, essa interface normalmente seria anotada com @Repository e estenderia JpaRepository — veremos isso na Aula 13.
2
Criar ClienteService com @Service
▶

Implemente um método que retorna a classificação do cliente ("VIP" se totalCompras > 5000, senão "Regular").

@Service
public class ClienteService {
    private final RepositorioCliente repositorio;

    public ClienteService(RepositorioCliente repositorio) {
        this.repositorio = repositorio;
    }

    public String classificar(Long id) {
        Cliente cliente = repositorio.buscarPorId(id);
        if (cliente == null)
            throw new IllegalArgumentException("Cliente não encontrado.");
        return cliente.getTotalCompras() > 5000 ? "VIP" : "Regular";
    }
}
O operador ternário (condição ? valorSeVerdadeiro : valorSeFalso) é uma forma compacta de escrever um if/else que retorna um valor.
3
Configurar a classe de teste
▶

Use @ExtendWith(MockitoExtension.class) — sem @SpringBootTest.

            @ExtendWith(MockitoExtension.class)
            class ClienteServiceTest {

            @Mock
            private RepositorioCliente repositorioMock;

            @InjectMocks
            private ClienteService clienteService;
            }
Note que essa estrutura é IDÊNTICA à que usamos desde a Aula 08 — a única novidade é a anotação @Service na classe testada.
4
Testar o cenário VIP
▶

Simule um cliente com total de compras acima de 5000.

@Test
void clienteComComprasAltasDeveSerVip() {
    Cliente cliente = new Cliente("Ana", 8000.0);
    when(repositorioMock.buscarPorId(1L)).thenReturn(cliente);

    assertEquals("VIP", clienteService.classificar(1L));
}
Repare que criamos o Cliente "de verdade" — só o RepositorioCliente é mockado, pois é a dependência EXTERNA.
5
Testar Regular e cliente não encontrado
▶

Complete a suíte com os outros dois cenários e rode todos os testes.

@Test
void clienteComComprasBaixasDeveSerRegular() { ... }

@Test
void clienteInexistenteDeveLancarExcecao() {
    when(repositorioMock.buscarPorId(99L)).thenReturn(null);
    assertThrows(IllegalArgumentException.class,
        () -> clienteService.classificar(99L));
}
Três testes, cobrindo os três caminhos de decisão (VIP, Regular, não encontrado) — pense na cobertura de branch da Aula 10!
